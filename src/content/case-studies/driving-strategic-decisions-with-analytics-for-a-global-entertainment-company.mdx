## Overview

## **Overview**

**About Customer**

The customer is a leading global entertainment enterprise with a strong presence across film, television, streaming, and interactive media. Publicly listed, the organization manages a large and diverse content library spanning tens of thousands of titles. By combining creative storytelling with advanced technology and data-driven insights, the company delivers high-quality original content and premium digital experiences to audiences worldwide, supporting large-scale productions, acclaimed series, and multi-platform engagement.

## The Challenge

## **Challenges**

As part of a broader initiative to strengthen digital analytics capabilities, the Global entertainment company aimed to establish a centralized, interactive dashboard to gain real-time visibility into website traffic and user engagement. Detailed access logs generated by AWS CloudFront were already available; the opportunity lay in transforming this rich data into clear, business-ready insights.

Leadership teams sought deeper visibility into traffic patterns, user locations, engagement behavior, and content performance across states and regions. To enable this, the analytics solution needed to enrich CloudFront log data with geolocation intelligence by resolving IP addresses using a standard geolocation database and present the insights through an intuitive, map-based dashboard with dynamic filters. This approach empowered business teams to explore regional trends independently and make faster, data-informed decisions with confidence.

## The Solution

## **Solution**

To address this, Comprinno designed a scalable solution to deliver state-wise analytics and regional content insights for the entertainment platform. The CloudFront logs were ingested into Amazon S3, and daily AWS Glue ETL jobs processed these logs by enriching them with geolocation details using the MaxMind GeoLite2 database stored in S3. The enriched datasets were stored in optimized Parquet format and cataloged through AWS Glue Crawlers, enabling Amazon Athena to query the data efficiently. QuickSight and Athena provide interactive, map-based dashboards, offering business teams detailed regional insights into content performance.

 

### **Key Actions:**

**Data Ingestion & Processing :**

- Configured CloudFront to deliver access logs directly to the S3 Raw Zone.

- Developed AWS Glue ETL jobs to process and enrich these logs with city, state, and country details using the MaxMind GeoLite2 database stored in S3.

- Stored the enriched datasets in the S3 processed bucket in optimized Parquet format, partitioned by processing date for efficient querying.

 

**Orchestration & Automation :**

- Used Amazon EventBridge to trigger a daily AWS Step Functions workflow that orchestrated the pipeline end to end.

- Step Functions coordinated the ETL job execution, Glue Crawler run, and success/failure tracking to ensure automated and reliable daily processing.

- Added retry logic and error handling for fault tolerance and operational stability.

 

** Query Optimization :**

- Configured AWS Glue Crawlers to automatically update the Data Catalog when new partitions were created.

- Used date-based partitioning in a Parquet file optimization in Athena  to improve query performance and reduce costs.

- Tuned SQL queries to reduce execution time and resource consumption.

 

**Visualization & Enablement :**

- Developed QuickSight dashboards with map-based visuals, state-level filters, and KPIs for content popularity by region.

- Integrated daily data refreshes from Athena, enabling business teams to explore the latest traffic insights independently.

 

**Testing & Optimization :**

- Validated ETL outputs for accuracy of geolocation enrichment and schema consistency before moving data to the Processed Zone.

- Monitored Athena query performance and optimized partitions to reduce latency.

- Developed tailored QuickSight dashboards that leveraged client feedback, providing interactive, intuitive visualizations and deeper insights for decision-making.

## 

## **Architecture ****Description**

The architecture was designed for automation, scalability, and reliability using a fully serverless approach. CloudFront access logs are automatically delivered to Amazon S3, where a daily EventBridge trigger initiates an AWS Step Functions workflow to orchestrate data processing. The workflow runs AWS Glue ETL jobs to transform and enrich logs with city, state, and country details using the MaxMind GeoLite2 database stored in S3. The enriched datasets are written back to an S3 processed bucket in optimized Parquet format and cataloged by AWS Glue Crawlers for efficient querying through Amazon Athena. Finally, Amazon QuickSight connects to Athena to deliver interactive, map-based dashboards that refresh daily, converting raw traffic logs into actionable regional insights with minimal operational effort.

## Results

## **Benefits**

- **State-wise Audience Insights** – Enriching CloudFront logs with geolocation data via the MaxMind GeoLite2 database offered precise insights into user locations. When combined with content identifiers, this allowed teams to pinpoint high-performing content and analyze regional traffic patterns effectively.

- **Cost-Efficient and Scalable Architecture **– Optimized storage using Parquet format, day-wise partitioning, and managed AWS services (S3, Glue, Athena, QuickSight) reduced query costs and allowed seamless scalability with growing traffic.

- **Centralized Traffic Analytics Dashboard** –  A unified QuickSight dashboard now provides a single source of truth for traffic analytics, enabling cross-team visibility and eliminating time-consuming, manual log analysis.

- **Empowering Decisions with Insights** – Customized QuickSight dashboards provided visibility into traffic trends, user geographies, and peak engagement periods, helping teams optimize content and enhance audience engagement.
